# for concepts 
| Folder       | Responsibility                          |
|-------------|------------------------------------------|
| models      | Database schema structure                |
| controllers | Business logic (what happens on request) |
| routes      | API endpoints (URL mapping)              |
| middlewares | Request/response processing logic        |
| db          | Database connection setup                |
| config      | App configuration (env, JWT, services)   |
| utils       | Helper / reusable utility functions      |
